## 🇩🇪 Deutsch

### Das HUD-Wetter — jetzt vollständig und dekodiert

Die Wetterzeile im In-Sim-HUD zeigte bisher den gekürzten METAR-Rohtext — bei langen Meldungen fiel ausgerechnet das Wichtigste hinten weg. Ab dieser Version liefert AeroACARS dem HUD die **dekodierten Werte seines eigenen Wetter-Dekoders** — derselbe, der die Wetterkarte in der App füllt. Statt abgeschnittenem Rohtext steht dort jetzt kompakt und vollständig:

`EDDB -SHRA 260/12kt VIS 10km+ TCU030 30/13 Q1011`

Also: Station, Wetter, Wind (mit Böen), Sicht, tiefste relevante Wolkenschicht, Temperatur/Taupunkt, QNH. Der Dekoder kennt dabei auch Wolkenschichten und Wettererscheinungen, die bisher nur die App-Anzeige hatte — HUD und App zeigen jetzt garantiert dasselbe.

Das **Browser-HUD** (`http://127.0.0.1:47847/hud`) hat die neue Anzeige sofort. Für das **Flow-Widget** folgt das aktualisierte Paket (v3.8) als Anhang an diesem Release — das bisherige v3.6 funktioniert weiter und steigt automatisch auf die neue Anzeige um, sobald es aktualisiert ist.

### Sonst

Keine Änderungen an Bewertung, Aufsetzerkennung oder PIREP-Übertragung. Kein Server-Deploy nötig.

## 🇬🇧 English

### HUD weather — now complete and decoded

The HUD's weather line used to show truncated raw METAR text — on long reports, the most important part was exactly what got cut off. Starting with this version, AeroACARS feeds the HUD the **decoded values from its own weather decoder** — the same one that fills the app's weather card. Instead of clipped raw text you now get, compact and complete:

`EDDB -SHRA 260/12kt VIS 10km+ TCU030 30/13 Q1011`

That is: station, weather, wind (with gusts), visibility, lowest relevant cloud layer, temperature/dewpoint, QNH. The decoder now also carries cloud layers and present weather that previously only the app's own display had — HUD and app are now guaranteed to show the same thing.

The **browser HUD** (`http://127.0.0.1:47847/hud`) picks up the new display immediately. For the **Flow widget**, the updated package (v3.8) will follow as an attachment on this release — the current v3.6 keeps working and switches to the new display automatically once updated.

### Otherwise

No changes to scoring, touchdown detection or PIREP filing. No server deploy required.
