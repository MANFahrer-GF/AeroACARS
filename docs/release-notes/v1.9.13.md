## 🇩🇪 Deutsch

### Lizenz und Zugang zum GSG-Server

- **Neue Lizenz:** AeroACARS ist ab dieser Version nur noch für Piloten der German Sky Group lizenziert (Text in `LICENSE`, Kurzfassung unter Einstellungen → Über). Frühere Versionen bleiben unter ihrer bisherigen MIT-Lizenz.
- **Skin, Kartenstil, VATGlasses-Sektoren und Discord-Anzeige** holt der Client jetzt mit deinem Anmelde-Token vom Server. Du merkst davon nichts – nach dem Start erscheinen sie wie bisher. Ohne Token (z. B. ganz ohne Anmeldung) bleibt die eingebaute Standarddarstellung.
- Das Token verlässt den Programmteil im Hintergrund nie; die Oberfläche bekommt nur die Antwort. Das gilt auch für das Tablet über die LAN-Brücke.

### Flugzeug vermessen: „Boden geprüft“

In der Übersicht zeigt die Spalte „Profil“ jetzt **„✓ Boden geprüft“** bzw. **„✓ Luft geprüft“**, wenn erst ein Teil des Profils anhand einer Messung bestätigt ist; der Tooltip nennt den fehlenden Teil. „geprüft“ steht nur noch, wenn Boden **und** Luft geprüft sind.

**Wichtig:** Aktualisiere bitte auf diese Version. Sobald der Server die Inhalte nur noch mit Anmeldung ausliefert, zeigen ältere Versionen die Standard-Skin und keine Sektoren. Fliegen, Aufzeichnen und Abgeben funktionieren mit jeder Version unverändert weiter.

**Hinweis für VA-Betreiber:** `aeroacars-live` ist bereits auf dem passenden Stand; der Server-Schalter `INHALTE_NUR_MIT_ANMELDUNG` wird erst gesetzt, wenn (fast) alle Piloten aktualisiert haben.

## 🇬🇧 English

### Licence and access to the GSG server

- **New licence:** from this version AeroACARS is licensed for German Sky Group pilots only (see `LICENSE`, short form under Settings → About). Earlier versions remain under their original MIT licence.
- **Skin, map style, VATGlasses sectors and Discord display** are now fetched from the server with your sign-in token. You will not notice any difference – they appear after start-up as before. Without a token (e.g. not signed in) the built-in default look is used.
- The token never leaves the background part of the app; the user interface only receives the response. This also holds for the tablet over the LAN bridge.

### Measure aircraft: “ground verified”

In the overview, the “Profile” column now shows **“✓ Ground verified”** or **“✓ Air verified”** when only one part of the profile has been confirmed by a measurement; the tooltip names the missing part. “verified” is only shown when ground **and** air are verified.

**Important:** please update. Once the server delivers this content to signed-in pilots only, older versions will show the default skin and no sectors. Flying, recording and filing work unchanged with any version.

**Note for VA operators:** `aeroacars-live` is already at the matching state; the server switch `INHALTE_NUR_MIT_ANMELDUNG` is only set once (almost) all pilots have updated.
