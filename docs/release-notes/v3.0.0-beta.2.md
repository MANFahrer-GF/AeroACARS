## 🇩🇪 Deutsch

### AeroACARS 3 – Beta 2

Ein kleines Update für alle, die Beta 1 fliegen. Es kommt automatisch über die Update-Anzeige.

**Neu**
- **Paket-Generation sichtbar:** Im Landebericht steht jetzt neben der AeroACARS-Version auch die Paket-Generation, mit der der Flug lief (zum Beispiel „AeroACARS 3.0.0-beta.2 · G61“). Die Verwaltung auf live sieht sie auch in der Liste der laufenden Flüge, und im PIREP erscheint sie als eigenes Feld „AeroACARS Paket“. Das hilft uns, wenn du einen Fehler meldest.
- **Neues Paket bereit:** Liegt ein neuer Paketstand bereit, zeigt das Hauptfenster ein Band mit „Jetzt neu starten“. Nach dem Neustart erklärt ein kurzer Hinweis, was in der neuen Generation neu ist.
- **Meine Anfragen:** Im Hilfe-Reiter stehen nur noch die drei wichtigsten Anfragen offen, der Rest lässt sich aufklappen.

**Behoben**
- **Chat auf dem iPad über die LAN-Brücke:** Die Tastatur schiebt die Seite nicht mehr aus dem Bild.

### Bitte beachten
- Weiterhin nicht gleichzeitig mit 2.x starten.
- Findest du einen Fehler, schick bitte eine Diagnose aus der App.

## 🇬🇧 English

### AeroACARS 3 – Beta 2

A small update for everyone flying Beta 1. It arrives automatically through the update notice.

**New**
- **Package generation visible:** The landing report now shows the package generation the flight ran with, next to the AeroACARS version (for example "AeroACARS 3.0.0-beta.2 · G61"). The admin pages on live also show it in the list of active flights, and the PIREP carries it as a separate field "AeroACARS Paket". This helps us when you report a problem.
- **New package ready:** When a new package is waiting, the main window shows a banner with "Restart now". After the restart, a short note explains what is new in that generation.
- **My requests:** The help tab now shows only the three most important requests; the rest can be expanded.

**Fixed**
- **Chat on the iPad via the LAN bridge:** The keyboard no longer pushes the page out of view.

### Please note
- Still do not run it at the same time as 2.x.
- If you find a problem, please send a diagnosis from the app.
