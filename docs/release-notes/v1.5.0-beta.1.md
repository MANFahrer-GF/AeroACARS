## 🇩🇪 AeroACARS v1.5.0-beta.1 — MSFS-In-Sim-Panel (Testbuild)

**Dies ist ein interner Testbuild, kein regulärer Release.** Er bleibt als Vorabversion markiert und erscheint deshalb nicht als „neueste Version" für andere Piloten — er dient ausschließlich dazu, das neue, experimentelle MSFS-In-Sim-Panel-Feature auf einem echten Windows/MSFS-2024-Rechner testen zu können.

**Neu (rein backend-seitig, für alle bestehenden Piloten unsichtbar):** ein neuer, eigenständiger, immer aktiver lokaler Server (Port 47847, ausschließlich `127.0.0.1`) liefert Flugstatus- und Landungsdaten für ein neues MSFS-2024-Toolbar-Panel, das Live-Anflugwerte und danach eine Landungs-Score-Karte direkt im Sim zeigt, ohne aus MSFS heraus alt-tabben zu müssen. Komplett getrennt von der bestehenden LAN-Fernbedienung (Port 8765, weiterhin PIN-geschützt, weiterhin optional) — beide Server laufen unabhängig nebeneinander.

Das eigentliche MSFS-Panel-Paket (`msfs-panel/` im Repo) ist noch ein Feasibility-Spike und wird separat über das MSFS SDK gebaut, nicht Teil dieses Installers.

Keine Wire-Format-Änderungen, keine Auswirkung auf Scoring/PIREP/Landung.

## 🇬🇧 AeroACARS v1.5.0-beta.1 — MSFS in-sim panel (test build)

**This is an internal test build, not a regular release.** It stays flagged as a prerelease and will not appear as "latest" to other pilots — it exists solely to test the new, experimental MSFS in-sim panel feature on a real Windows/MSFS 2024 machine.

**New (backend-only, invisible to all existing pilots):** a new, independent, always-on local server (port 47847, `127.0.0.1` only) serves flight-status and landing data for a new MSFS 2024 toolbar panel that shows live approach telemetry and then a landing score card directly in the sim, without alt-tabbing out. Fully separate from the existing LAN Remote Control server (port 8765, still PIN-protected, still opt-in) — both servers run independently side by side.

The actual MSFS panel package (`msfs-panel/` in the repo) is still a feasibility spike and is built separately via the MSFS SDK, not part of this installer.

No wire-format changes, no impact on scoring/PIREP/landing logic.
