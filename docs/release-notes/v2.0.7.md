## 🇩🇪 Deutsch

### Verzögerung beim Ausrollen jetzt auch auf der Webseite

Die Kachel „Verzögerung“ unter „Aufsetz-Qualität“ zeigte in der App einen Wert, auf der Live-Webseite aber immer „—“.

- **Ursache:** Die Verzögerung steht erst fest, wenn das Ausrollen beendet ist. Die Landung geht aber schon wenige Sekunden nach dem Aufsetzen an den Server, und der spätere Nachtrag zum Ausrollende trug den Wert nicht mit.
- **Jetzt:** Die Verzögerung kommt mit diesem Nachtrag an. App und Webseite zeigen denselben Wert.
- **Ältere Landungen:** Seit Version 2.0.1 wurde sie auf dem Server aus den Landungssicherungen nachgetragen.

---

## 🇬🇧 English

### Rollout deceleration now on the website too

The "Deceleration" tile under "Touchdown quality" showed a value in the app but always "—" on the live website.

- **Cause:** The deceleration is only known once the rollout has ended. The landing is sent to the server a few seconds after touchdown, and the later update at the end of the rollout did not carry the value.
- **Now:** The deceleration arrives with that update. App and website show the same value.
- **Older landings:** For landings since version 2.0.1 it has been filled in on the server from the landing backups.
