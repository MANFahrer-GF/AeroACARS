## 🇬🇧 English

### New: Synaptic A220 (-100 / -300) becomes a premium aircraft

AeroACARS now detects the brand-new Synaptic A220 as its own profile and reads, on top of the normal flight data:

- **Flight guidance modes** (the Airbus/Boeing "FMA" equivalent) — LNAV/Heading/Approach laterally, Altitude/VNAV/Vertical-Speed/Flight-Path-Angle/Flight-Level vertically
- **Master Caution / Master Warning** — the real annunciator lamps
- **Autobrake** and the **aircraft's own flight phase** — captured, but not yet translated to plain-text labels (see note below)

Detection is title-based, deliberately with **no** ICAO fallback — so other A220 variants or future third-party addons won't collide with this profile.

**Honesty note:** this profile was built entirely from the official Synaptic documentation *before* the aircraft was even installed — there has been no real test flight yet. Two things are deliberately cautious as a result:

1. The vendor docs only list the Autobrake and flight-phase values by name (e.g. "RTO/OFF/LO/MED/HI"), without saying which name maps to which number. Rather than guess, we currently show the raw value (e.g. "#2") — the real label lands once the first flight confirms the mapping.
2. No V-speed variables (V1/VR/V2/VAPP/VLS) are documented — those stay empty on this aircraft for now.

All other aircraft are provably unaffected by this change (the new sources are strictly gated to the A220 profile and tested).
