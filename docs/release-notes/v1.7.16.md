## 🇩🇪 Deutsch

Ein Flug nach Palma (LEPA) zeigte keine Ankunfts-Parkposition, obwohl
OpenStreetMap für den Platz 328 kartierte Stände kennt. Der Grund war
nicht, dass die Karte fehlt — sondern dass wir überhaupt auf eine
Drittquelle angewiesen waren, während der Simulator die Position die ganze
Zeit selbst kennt: Wer in X-Plane oder MSFS startet, wählt die Parkposition
meist schon im Ladebildschirm.

### Was jetzt anders ist

Gate/Stand kommen ab sofort zuerst aus der installierten Szenerie —
X-Plane liest sie aus derselben `apt.dat`, aus der schon die Bahndaten
kommen (seit 1.7.8); MSFS fragt sie über dieselbe SimConnect-Schnittstelle
an. OpenStreetMap bleibt das Netz für Plätze, deren Szenerie selbst keine
Parkpositionen führt — wie bisher, nur nicht mehr die einzige Quelle.

Das betrifft in dieser Version die **Ankunftsseite**: Der Stand, an dem
ihr abgestellt habt, wird jetzt zuverlässiger erkannt, auch an Plätzen, an
denen OpenStreetMap lückenhaft oder veraltet ist. Die Abflugseite bleibt
vorerst wie bisher bei OpenStreetMap — dafür bräuchte es eine eigene
Abfrage direkt beim Start, die noch aussteht.

Für euch ändert sich nichts an der Bedienung — nur dass an mehr Plätzen
tatsächlich ein Gate im PIREP steht, statt leer zu bleiben.

## 🇬🇧 English

A flight to Palma (LEPA) showed no arrival parking position, even though
OpenStreetMap has 328 mapped stands for that airport. The reason wasn't a
missing map — it was that we relied on a third-party source at all, while
the simulator already knows the position the whole time: starting in
X-Plane or MSFS usually means picking your parking spot right on the
loading screen.

### What changed

Gate/stand detection now checks the installed scenery first — X-Plane
reads it from the same `apt.dat` that already supplies runway data (since
1.7.8); MSFS queries it through the same SimConnect interface.
OpenStreetMap remains the fallback for airports whose scenery itself has
no parking data — same as before, just no longer the only source.

In this version that covers the **arrival side**: the stand you shut down
at is now detected more reliably, including at airports where
OpenStreetMap is sparse or outdated. Departure-side detection still uses
OpenStreetMap for now — that would need its own request right at engine
start, which is still open.

Nothing changes in how you use the app — just that a gate now shows up in
the PIREP at more airports, instead of staying empty.
