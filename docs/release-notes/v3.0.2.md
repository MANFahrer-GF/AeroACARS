## 🇩🇪 Deutsch

### AeroACARS 3.0.2

**Behoben**
- **Ruckler vor dem Aufsetzen macht die Landung nicht mehr härter:** Hing der Simulator kurz vor dem Aufsetzen für einen Moment, las AeroACARS aus der Höhenkurve eine viel zu hohe Sinkrate (in einem Fall −661 statt −204 fpm), und das Flugzeug kam unnötig in die Wartung. AeroACARS erkennt solche Stillstände jetzt und misst nur mit Bildern, die der Simulator wirklich neu gezeichnet hat. Bei sauberen Landungen ändert sich nichts.
- **Vollständige Flottenliste bei jeder Airline:** Liefert der Server einer Airline nur wenige Flugzeuge je Seite, lud AeroACARS bisher nur die erste Seite. Jetzt lädt AeroACARS alle Seiten.

**Verbessert**
- Die Aufsetz-Sinkrate misst AeroACARS jetzt mit dem Bewertungsmodul aus dem Paket. Verbesserungen dieser Messung kommen künftig mit einer neuen Generation, ohne neuen Client.

### Bitte beachten
- Startet AeroACARS nach dem Update auf dem Mac nicht von selbst neu, öffne bitte **AeroACARS 3** selbst.

## 🇬🇧 English

### AeroACARS 3.0.2

**Fixed**
- **A stutter before touchdown no longer makes the landing harder:** if the simulator froze for a moment just before touchdown, AeroACARS read a far too high sink rate from the height curve (in one case −661 instead of −204 fpm), and the aircraft went into maintenance for no reason. AeroACARS now detects such freezes and measures only with frames the simulator really redrew. Clean landings are not affected.
- **Complete fleet list for every airline:** if an airline's server returned only a few aircraft per page, AeroACARS loaded only the first page. AeroACARS now loads all pages.

**Improved**
- AeroACARS now measures the touchdown rate with the scoring module from the package. Future improvements to this measurement arrive with a new generation, without a new client.

### Please note
- If AeroACARS does not restart by itself after the update on Mac, please open **AeroACARS 3** yourself.
