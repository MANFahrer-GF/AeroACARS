## 🇩🇪 Deutsch

Diese Version findet X-Plane zuverlässiger, wenn du das X-Plane-Plugin installierst.

### Auto-Erkennung des X-Plane-Ordners verbessert

Die „Auto-Erkennung" unter **Einstellungen → Plugins → X-Plane Premium Plugin** fand X-Plane bisher nur in wenigen festen Ordnern, etwa `C:\X-Plane 12` oder `/Applications/X-Plane 12`. Lag X-Plane auf einer anderen Platte, in einem eigenen Ordner oder über Steam installiert, musste der Pfad von Hand eingetragen werden.

Jetzt liest AeroACARS zuerst die Liste, die X-Plane selbst über seine Installationsorte führt. Damit wird X-Plane gefunden, egal wo es liegt, solange es einmal gestartet wurde. Stehen dort noch Einträge zu gelöschten Installationen, werden sie übersprungen. Zusätzlich kennt die Erkennung jetzt die üblichen Steam-Ordner. Unter Windows bricht die Suche außerdem nicht mehr vorzeitig ab, wenn die Registry nicht gelesen werden kann.

Findet die Auto-Erkennung trotzdem nichts, hilft weiter der Knopf **„Ordner wählen …"**.

### Hinweis für VA-Betreiber

Der Client braucht keine Server-Änderung (`aeroacars-live`).

## 🇬🇧 English

This version finds X-Plane more reliably when you install the X-Plane plugin.

### Better auto-detection of the X-Plane folder

"Auto-detect" under **Settings → Plugins → X-Plane Premium Plugin** used to find X-Plane only in a few fixed folders such as `C:\X-Plane 12` or `/Applications/X-Plane 12`. If X-Plane was on another drive, in a custom folder or installed via Steam, the path had to be typed in by hand.

AeroACARS now first reads the list X-Plane itself keeps of its install locations. X-Plane is found wherever it is, as long as it has been started once. Entries for deleted installs are skipped. Detection also knows the usual Steam folders now. On Windows the search no longer stops early when the registry cannot be read.

If auto-detect still finds nothing, the **"Choose folder…"** button is still there.

### Note for VA operators

The client needs no server change (`aeroacars-live`).
