## 🇩🇪 Deutsch

### Auto-Start: „Start läuft“ statt einer Meldung, die wie ein Fehler aussah

- **Während der Auto-Start deinen Flug anlegt, steht dort jetzt „Auto-Start läuft“.** Das dauert ein paar Sekunden. Bisher stand in dieser Zeit „Bid … wurde diese Session schon mal auto-gestartet“, und das las sich wie ein Fehler, obwohl alles in Ordnung war. Der gelbe Hinweis in der Buchungsliste hat dafür jetzt die Überschrift „Auto-Start läuft“ statt „gerade nicht möglich“ und verschwindet, sobald der Flug läuft.
- **Nur ein Auto-Start zur selben Zeit.** Passen mehrere gebuchte Flüge zu deinem Standort, konnte während eines laufenden Starts ein zweiter anlaufen und den ersten stören. Jetzt wartet der Auto-Start, bis der erste Start fertig ist.
- **Sauberes Aufräumen nach einem abgebrochenen Start.** Bricht ein automatischer Start unerwartet ab, gibt die App die Buchung wieder frei und wartet zwei Minuten, bevor sie es erneut versucht, statt es im Sekundentakt zu wiederholen.

## 🇬🇧 English

### Auto-start: "In progress" instead of a message that looked like an error

- **While auto-start is creating your flight, it now says "Auto-start in progress".** This takes a few seconds. Until now it said "Bid … was already auto-started this session" during that time, which read like an error although everything was fine. The yellow notice in the bookings list now has the heading "Auto-start in progress" instead of "currently not possible" and disappears as soon as the flight is running.
- **Only one auto-start at a time.** If several booked flights matched your position, a second start could begin while the first was still running and interfere with it. Auto-start now waits until the first start has finished.
- **Clean-up after an aborted start.** If an automatic start ends unexpectedly, the app releases the booking again and waits two minutes before trying again, instead of repeating it every few seconds.
