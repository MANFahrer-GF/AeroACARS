## 🇬🇧 English

### PDF export

- **"Export PDF" (Landing tab) did nothing at all on macOS.** Root cause found via an old, never-triaged error report (sitting unnoticed since 2026-06-13): Tauri's own permission system (ACL) was blocking the print command with `Command plugin:webview|print not allowed by ACL` — the required permission was simply missing from the app config. One line added, now allowed.
- Also hardened for any other way the print dialog might fail to complete cleanly: a failure is now reported visibly instead of failing silently, and a 20s safety timeout frees the button regardless, instead of staying permanently stuck.

### Display bugs

- **Long info panels (e.g. "Runway utilization — how the score is built", the flight-start confirmation, the glossary) couldn't be scrolled and grew past the edge of the screen** — the "Close" button ended up out of view. Affected every panel of this kind together; fixed uniformly.
- **Two notice banners** (weather-briefing loading hint, OFP-refresh notice in the flight list) **were hardcoded to fixed colors instead of the app's theme** — in light mode they looked jarringly dark. Now consistent with the rest of the app.
- **Right-click showed the native, out-of-place grey system menu** with no function relevant to the app — now suppressed in the desktop build.

**Full Changelog**: https://github.com/MANFahrer-GF/AeroACARS/compare/v1.4.4...v1.4.5
