## 🇩🇪 Deutsch

### Schnellerer Start

AeroACARS ist nach dem Start rund **6 Sekunden schneller** einsatzbereit. Beim Anmelden holte der Client bisher dein Profil samt der kompletten Flottenliste deines Rangs (über 1 MB) – davon brauchte er nur den Rangnamen. Jetzt kommt nur das Profil (1,3 statt 8 Sekunden). Erst danach verbindet sich AeroACARS mit dem Simulator; das geht nun entsprechend früher. Dasselbe gilt beim Anmelden und beim Auffrischen des Profils.

### Simulator automatisch erkennen

In **Einstellungen → Simulator** gibt es die neue Auswahl **„Automatisch“**. AeroACARS erkennt dann selbst, ob MSFS 2020, MSFS 2024, X-Plane 11 oder X-Plane 12 läuft, und stellt sich darauf ein. Darunter steht, welcher Simulator gerade eingestellt ist.

- **Während eines Flugs wird nie umgestellt.**
- Laufen zwei Simulatoren gleichzeitig, bleibt es beim bisherigen.
- **Deine bisherige Einstellung bleibt, wie sie ist.** „Automatisch“ ist nur bei einer neuen Installation voreingestellt; wer möchte, stellt es selbst ein. Die feste Auswahl eines Simulators geht weiterhin jederzeit.
- Läuft der Simulator auf einem anderen Rechner als AeroACARS, bitte den Simulator fest auswählen – die Erkennung sieht nur Programme auf demselben PC.

### Kleinigkeiten

- MSFS 2024: Beim Flugzeugwechsel lehnt der Simulator das Abmelden der Schalter-Abfragen des vorigen Flugzeugs ab. Das ist erwartet und steht nicht mehr als Warnung im Protokoll.
- Mac: X-Plane wird bei einem Verbindungsabriss wieder richtig als „läuft noch“ bzw. „beendet“ erkannt.

## 🇬🇧 English

### Faster start-up

AeroACARS is ready about **6 seconds sooner** after start-up. On sign-in the client used to fetch your profile together with the complete fleet list of your rank (over 1 MB) – it only needed the rank name. Now it fetches just the profile (1.3 instead of 8 seconds). AeroACARS only connects to the simulator after that, so this now happens correspondingly earlier. The same applies when signing in and refreshing the profile.

### Automatic simulator detection

**Settings → Simulator** has a new option **“Automatic”**. AeroACARS then detects by itself whether MSFS 2020, MSFS 2024, X-Plane 11 or X-Plane 12 is running and sets itself up accordingly. Below it shows which simulator is currently selected.

- **It never switches during a flight.**
- If two simulators are running at the same time, it keeps the current one.
- **Your existing setting stays as it is.** “Automatic” is only preselected on a new installation; switch to it yourself if you like. Choosing a fixed simulator remains possible at any time.
- If the simulator runs on a different computer than AeroACARS, please select it manually – detection only sees programs on the same PC.

### Small fixes

- MSFS 2024: when changing aircraft, the simulator rejects unsubscribing the previous aircraft's switch queries. This is expected and no longer logged as a warning.
- Mac: X-Plane is correctly recognised again as “still running” or “closed” after a connection drop.
