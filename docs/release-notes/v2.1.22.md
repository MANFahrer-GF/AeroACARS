## 🇩🇪 Deutsch

### Neu: Windscherung im Anflug wird erkannt

Ändern sich im Anflug Gegenwind und Fahrt innerhalb weniger Sekunden gemeinsam um mindestens 15 kt, nennt AeroACARS das jetzt in der Landeauswertung. Das hilft, einen unruhigen Anflug richtig einzuordnen: Eine Windscherung ist Wetter, kein Flugfehler.

- **Wo:** im Landungs-Tab unter „Anflugruhe“, zum Beispiel „Windscherung in 1.480 ft: In 5 s änderten sich Gegenwind um −31 kt und Fahrt um −28 kt.“ Dieselbe Zeile steht auf der Webseite.
- **Wann:** zwischen 30 und 1.500 ft über der Schwelle. Gemessen wird mit dem Wind, den der Simulator meldet. Ändert sich nur die Fahrt, etwa weil du Schub wegnimmst, ist das keine Windscherung.
- **Keine Auswirkung auf die Note.** Die Zeile ist ein reiner Hinweis.
- **Wie oft:** Bei knapp 1.900 ausgewerteten GSG-Flügen kam das dreimal vor. Bei ruhigem Wetter siehst du die Zeile also nicht.

### Rollwege mit gleichem Namen an zwei Stellen einer Bahn

An manchen Flughäfen gibt es denselben Rollweg-Namen zweimal an einer Bahnseite, mehrere hundert Meter auseinander (zum Beispiel in Paris-Charles de Gaulle oder Miami). Bisher zeigte die Bahnansicht dann nur eine dieser Ausfahrten. Ist ein Pilot über die andere abgerollt, fehlte deren Name. Jetzt erscheinen beide.

### Für VA-Betreiber

- Damit die Windscherung auch auf der Webseite erscheint, braucht aeroacars-live den Stand vom 28.10.2026. Auf live.kant.ovh ist er bereits ausgerollt. Ein älterer Server zeigt die Zeile einfach nicht, sonst ändert sich nichts.
- Panel, Flow-Widget und X-Plane-Plugin brauchen kein Update.

## 🇬🇧 English

### New: wind shear on approach is detected

If headwind and airspeed change together by at least 15 kt within a few seconds on approach, AeroACARS now names it in the landing analysis. This helps you read an unsteady approach correctly: wind shear is weather, not a piloting error.

- **Where:** in the landing tab under “Approach steadiness”, for example “Wind shear at 1,480 ft: within 5 s the headwind changed by −31 kt and the airspeed by −28 kt.” The same line appears on the website.
- **When:** between 30 and 1,500 ft above the threshold, measured with the wind the simulator reports. If only the airspeed changes, for example because you pull the thrust back, that is not wind shear.
- **No effect on the score.** The line is information only.
- **How often:** across almost 1,900 analysed GSG flights it happened three times. In calm weather you will not see the line.

### Taxiways with the same name at two places on one runway

At some airports the same taxiway name exists twice on one side of a runway, several hundred metres apart (for example at Paris-Charles de Gaulle or Miami). The runway view used to show only one of these exits. If a pilot vacated via the other one, its name was missing. Both now appear.

### For VA operators

- For the wind shear line to appear on the website as well, aeroacars-live needs the version of 28 Oct 2026. It is already deployed on live.kant.ovh. An older server simply does not show the line; nothing else changes.
- Panel, Flow widget and X-Plane plugin do not need an update.
