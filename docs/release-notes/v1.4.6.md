## 🇩🇪 Deutsch

### Bahn-Erkennung

- **Landungen wurden an manchen Flughäfen der falschen Bahn zugeordnet** — z. B. EFTP/Tampere-Pirkkala, wo statt der echten Bahn "24" (2700 m) eine kürzere "24C" mit falscher Position im Bericht stand (gemeldet über einen Feldreport, per Google-Maps-Abgleich der Aufsetz-Koordinate entdeckt). Ursache: die Navigraph-Navdatenquelle enthält an 38 Flughäfen weltweit einen zusätzlichen, fehlerhaften Bahn-Eintrag mit fast identischer Peilung wie eine reale Bahn, aber längs versetzt — der bisherige Abstands-Abgleich konnte das nicht von echten Parallelbahnen unterscheiden.
- Neuer Abgleich gegen die öffentliche OurAirports-Referenz filtert solche Phantom-Einträge jetzt heraus, bevor überhaupt gematcht wird — sowohl beim Landungsbericht als auch beim live im Anflug angezeigten Gleitwinkel-Hinweis. Historisch bereits gemeldete Landungen bleiben unverändert (kein rückwirkender Eingriff in bereits gezählte PIREPs).
- Eingebaute Referenzdaten (Flughäfen + Bahnen, Quelle OurAirports.com) aktualisiert.

**Full Changelog**: https://github.com/MANFahrer-GF/AeroACARS/compare/v1.4.5...v1.4.6

## 🇬🇧 English

### Runway detection

- **Landings at some airports were matched to the wrong runway** — e.g. EFTP/Tampere-Pirkkala, where the report showed a shorter "24C" at the wrong position instead of the real runway "24" (2700 m), reported via a field report and discovered by comparing the touchdown coordinate against Google Maps. Root cause: the Navigraph navdata source carries an extra, erroneous runway entry at 38 airports worldwide with a heading nearly identical to a real runway but offset along its length — the previous distance-based matcher couldn't tell it apart from genuine parallel runways.
- A new cross-check against the public OurAirports reference now filters these phantom entries out before matching happens at all — both for the landing report and for the live in-flight glideslope advisory. Landings already reported historically are left untouched (no retroactive change to already-counted PIREPs).
- Refreshed the embedded reference data (airports + runways, sourced from OurAirports.com).

**Full Changelog**: https://github.com/MANFahrer-GF/AeroACARS/compare/v1.4.5...v1.4.6
