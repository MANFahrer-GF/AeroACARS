## 🇩🇪 Deutsch

### AeroACARS 3 – Beta 2.3

Ein kleiner Nachtrag zu Beta 2.2. Er kommt automatisch über die Update-Anzeige.

**Neu**
- **Hoppie-Logon-Code sichtbar:** Unter Einstellungen › Cockpit steht dein hinterlegter Hoppie-Logon-Code jetzt im Klartext, damit du nachprüfen kannst, ob er stimmt. Beim Eintippen siehst du den Code ebenfalls im Klartext statt als Punkte. Angezeigt wird er nur am Sim-PC selbst, über die LAN-Fernbedienung (Tablet) nicht.

### Bitte beachten
- Startet AeroACARS nach dem Update auf dem Mac nicht von selbst neu, öffne bitte **AeroACARS 3** selbst, nicht das daneben installierte AeroACARS 2.
- Weiterhin nicht gleichzeitig mit 2.x starten.
- Findest du einen Fehler, schick bitte eine Diagnose aus der App.

## 🇬🇧 English

### AeroACARS 3 – Beta 2.3

A small follow-up to Beta 2.2. It arrives automatically through the update notice.

**New**
- **Hoppie logon code visible:** Under Settings › Cockpit your stored Hoppie logon code is now shown in plain text, so you can check that it is correct. While typing, the code is shown in plain text too instead of dots. It is only shown on the sim PC itself, not via the LAN remote (tablet).

### Please note
- If AeroACARS does not restart by itself after the update on Mac, please open **AeroACARS 3** yourself, not the AeroACARS 2 installed next to it.
- Still do not run it at the same time as 2.x.
- If you find a problem, please send a diagnosis from the app.
