## 🇬🇧 English

### iFly 737 MAX — profile audit

- **Parking brake:** The display now reads the iFly's actual brake lever instead of the standard SimVar, which falsely reported "released" for minutes after powering up the aircraft.
- **Flaps:** Boeing aircraft now show real Boeing detents (UP, 1, 2, 5, 10, 15, 25, 30, 40) instead of Airbus labels like "1+F".
- **Flap log debounced:** Brief intermediate values while moving through the detents (e.g. a 3-second "FULL") no longer end up in the activity log.
- **Autobrake:** The iFly selector is now decoded correctly (RTO, OFF, 1, 2, 3, MAX).
- **A/THR:** Shows "ARMED" on the iFly instead of incorrectly "ENGAGED".

### HUD & widget

- **Time-to-arrival (ETE) sanity check:** The ETE only appears once it drops below 1.3× the planned flight time — no more fantasy values right after departure.
- **Time cell auto-rotates:** ETE, arrival time (ETA) and elapsed time (FLT) now cycle automatically every 8 seconds.
- **Browser HUD:** The /hud page is now transparent and compact — the strip ends right after the text, ideal as an overlay.
- **Flow widget v3.9** is available for download (crew center → ACARS tools).
