## 🇩🇪 Deutsch

### iniBuilds A350: Transponder richtig erkannt

Die erste Messung mit „Flugzeug vermessen“ aus der Community (danke, Thorben!) hat beim A350 einen Fehler aufgedeckt:

- **Transponder auf ALT ohne TCAS** wurde als **„STBY“** angezeigt. Der A350 meldet für „TCAS aus“ denselben Wert, egal ob der Transponder auf STBY oder ALT steht. AeroACARS unterscheidet das jetzt über den Transponder-Zustand selbst. Damit stimmt auch der Haken im Bordbuch beim Start.
- **TA ONLY und TA/RA** sind jetzt am echten Flugzeug bestätigt, ebenso Strobes, Anschnallzeichen, Spoiler ARMED, Autobrake und APU.

### Flugzeug vermessen

- **Genauere Ergebnisse:** Werte, die sich nur minimal verändern (etwa eine Temperatur, die um Tausendstel driftet), gelten nicht mehr als Schalter. Die Messung zeigt dadurch nur noch, was wirklich mit dem Schalter mitgeht.
- **iniBuilds A380:** Die Messung liest jetzt auch die Variablennamen des A350 mit (beide iniBuilds). So können wir beim nächsten A380-Transpondertest sehen, ob der TCAS-Modus dort genauso lesbar ist.

## 🇬🇧 English

### iniBuilds A350: transponder detected correctly

The first community measurement with "Measure aircraft" (thanks, Thorben!) uncovered a bug on the A350:

- **Transponder on ALT without TCAS** was shown as **"STBY"**. The A350 reports the same value for "TCAS off" whether the transponder is on STBY or ALT. AeroACARS now tells them apart using the transponder state itself. This also fixes the take-off tick in the SOP Check.
- **TA ONLY and TA/RA** are now confirmed on the real aircraft, as are strobes, seat belt sign, spoilers armed, autobrake and APU.

### Measure aircraft

- **More accurate results:** values that only change minimally (such as a temperature drifting by thousandths) no longer count as switches. The measurement now only shows what really follows the switch.
- **iniBuilds A380:** the measurement now also reads the A350's variable names (both iniBuilds). So on the next A380 transponder test we can see whether the TCAS mode is readable there too.
