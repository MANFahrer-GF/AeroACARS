## 🇩🇪 Deutsch

### AeroACARS 3 – Beta 1

Das ist die erste Beta von AeroACARS 3, zunächst für die Vorab-Tester. Fliegen kannst du damit wie mit 2.x. Unter der Haube ist AeroACARS aber neu gebaut: Vieles, was früher ein neues Programm brauchte, kommt jetzt als signiertes Datenpaket vom Server.

**Neu**
- **Eigene App neben 2.x:** AeroACARS 3 installiert sich als eigenes Programm „AeroACARS 3“. Dein 2.x bleibt unverändert.
- **Deine Daten kommen mit:** Beim ersten Start übernimmt AeroACARS 3 Anmeldung, Einstellungen, Bordbuch, Landungen und Hoppie-Code aus 2.x, als Kopie.
- **Datenpaket statt Update:** Grenzwerte, Flugzeugprofile (X-Plane und MSFS), Flughäfen, Texte DE/EN/IT, Tabellen, die Landebewertung, der Ablauf der Kabinenansagen und die Oberfläche selbst kommen aus einem signierten Paket. Korrekturen daran brauchen kein neues Programm mehr. Ist das Paket einmal nicht da, läuft der eingebaute Stand.
- **Landebewertung als Modul:** Die Note rechnet ein eigenes, geprüftes Modul – auf deinem Rechner und, falls dort etwas schiefgeht, genauso auf dem Server. Fällt das Modul aus dem Paket aus, steht an der Note „vorläufig“; geht gar nichts, steht „nicht bewertet“ und der Server rechnet nach. Über 1 800 Flüge aus 2.x wurden damit nachgerechnet.
- **Jeder Aufsetzer zählt einzeln:** Bei Touch-and-Go und Hopsern werden alle Aufsetzer mit ihren Messdaten an den Server gesendet; fehlt die Verbindung, wird nachgesendet.
- **Kabinenansagen:** Nach einer Umleitung kündigt die Kabine jetzt das neue Ziel an, auch nach einem Durchstarten. Fehlt ein Text, heißt es „Text fehlte“ statt „Ton nicht fertig“.
- **Sicherer:** Alles, was deinen Rechner betrifft (Anmelden, Plugin installieren, Daten löschen, Autostart, Einwilligung), bestätigst du in einem eigenen Fenster. Vom Tablet über die LAN-Brücke gehen solche Aktionen nur mit Bestätigung am Sim-PC.
- **Flugkarte:** dieselbe Karte im Programm und in der Verwaltung auf live.
- **Statusseite:** `live.kant.ovh/status` zeigt, ob alle Dienste laufen, und kündigt Wartungen an.

### Bitte beachten
- **Nicht gleichzeitig mit 2.x starten.** Beide Programme hören auf dieselben Simulator-Anschlüsse.
- **Einen offenen 2.x-Flug in 2.x zu Ende fliegen.** Offene Flüge und noch nicht gesendete Berichte werden bewusst nicht übernommen.
- **Einstellungen der Oberfläche einmal neu setzen:** Sprache und einige Schalter der Oberfläche beginnen beim ersten Start neu. Fehlerberichte, Tray und automatisches Löschen alter Flugprotokolle fragt AeroACARS einmal über das Bestätigungsfenster ab.
- Findest du einen Fehler, schick bitte eine Diagnose aus der App.

## 🇬🇧 English

### AeroACARS 3 – Beta 1

This is the first beta of AeroACARS 3, first for pre-release testers. You fly with it just like with 2.x, but it has been rebuilt underneath: much of what used to need a new program now comes as a signed data package from the server.

**New**
- **Separate app next to 2.x:** AeroACARS 3 installs as its own program, "AeroACARS 3". Your 2.x stays unchanged.
- **Your data comes along:** On first start, AeroACARS 3 copies your login, settings, logbook, landings and Hoppie code from 2.x.
- **Data package instead of updates:** Limits, aircraft profiles (X-Plane and MSFS), airports, texts in DE/EN/IT, tables, the landing score, the cabin announcement schedule and the interface itself come from a signed package. Fixes no longer need a new program. If the package is not available, the built-in version runs.
- **Landing score as a module:** A separate, tested module calculates the score – on your computer and, if something goes wrong there, the same way on the server. If the package module fails, the score is marked "provisional"; if nothing works, it says "not scored" and the server recalculates it. More than 1,800 flights from 2.x were recalculated with it.
- **Every touchdown counts:** For touch-and-goes and bounces, every touchdown is sent to the server with its measurements; without a connection it is sent later.
- **Cabin announcements:** After a diversion the cabin now announces the new destination, also after a go-around. A missing text is shown as "text missing" instead of "audio not ready".
- **Safer:** Everything that affects your computer (login, installing plugins, deleting data, autostart, consent) is confirmed in a separate window. From a tablet via the LAN bridge such actions need confirmation on the sim PC.
- **Flight map:** the same map in the program and in the admin pages on live.
- **Status page:** `live.kant.ovh/status` shows whether all services are running and announces maintenance.

### Please note
- **Do not run it at the same time as 2.x.** Both programs listen on the same simulator ports.
- **Finish an open 2.x flight in 2.x.** Open flights and reports not yet sent are deliberately not copied.
- **Set your interface settings once more:** Language and some interface switches start fresh on first start. Error reports, tray and automatic deletion of old flight logs are asked once in the confirmation window.
- If you find a bug, please send a diagnosis from the app.
