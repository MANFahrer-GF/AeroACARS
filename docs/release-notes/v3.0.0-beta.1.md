## 🇩🇪 Deutsch

### AeroACARS 3 – erste Vorabversion

Das ist der erste Testlauf von AeroACARS 3. Er ist nur für Vorab-Tester gedacht. Fliegen kannst du damit wie mit 2.x, im Hintergrund ist aber vieles neu gebaut.

- **Eigene App neben 2.x:** AeroACARS 3 installiert sich als eigenes Programm „AeroACARS 3“. Dein AeroACARS 2.x bleibt unverändert und funktioniert weiter.
- **Deine Daten kommen mit:** Beim ersten Start übernimmt AeroACARS 3 Anmeldung, Einstellungen, Bordbuch, Landungen und Hoppie-Code aus 2.x, als Kopie. Bei 2.x ändert sich nichts.
- **Daten ohne neue Version:** Grenzwerte, Flugzeugprofile, Flughäfen, Texte und weitere Tabellen kommen aus einem signierten Datenpaket. Korrekturen daran brauchen künftig kein neues Programm mehr. In dieser Vorabversion gilt noch das eingebaute Paket.
- **Neue MSFS-Flugzeuge ohne Update:** Für Add-ons, die AeroACARS noch nicht kennt, lassen sich Lichter, Autopilot und Schilder künftig über das Datenpaket anbinden.

### Bitte beachten

- **Nicht gleichzeitig mit 2.x starten.** Beide Programme hören auf dieselben Simulator-Anschlüsse.
- **Einen offenen 2.x-Flug in 2.x zu Ende fliegen.** Offene Flüge und noch nicht gesendete Berichte werden bewusst nicht übernommen, damit nichts doppelt abgegeben wird.
- **Sprache einmal neu wählen**, falls sie nicht stimmt.
- Findest du einen Fehler, schick bitte eine Diagnose aus der App.

## 🇬🇧 English

### AeroACARS 3 – first pre-release

This is the first test build of AeroACARS 3, meant for pre-release testers only. You fly with it just like with 2.x, but much of it has been rebuilt underneath.

- **Separate app next to 2.x:** AeroACARS 3 installs as its own program, "AeroACARS 3". Your AeroACARS 2.x stays unchanged and keeps working.
- **Your data comes along:** On first start, AeroACARS 3 copies your login, settings, logbook, landings and Hoppie code from 2.x. Nothing changes in 2.x.
- **Data without a new version:** Limits, aircraft profiles, airports, texts and other tables come from a signed data package, so fixes no longer need a new program. This pre-release still uses the built-in package.
- **New MSFS aircraft without an update:** Lights, autopilot and signs of add-ons AeroACARS does not know yet can later be connected through the data package.

### Please note

- **Do not run it at the same time as 2.x.** Both programs listen on the same simulator ports.
- **Finish an open 2.x flight in 2.x.** Open flights and reports not yet sent are deliberately not copied, so nothing is filed twice.
- **Choose your language once more** if it is not right.
- If you find a bug, please send a diagnosis from the app.
