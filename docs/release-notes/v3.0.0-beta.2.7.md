## 🇩🇪 Deutsch

### AeroACARS 3 – Beta 2.7

Diese Version sorgt dafür, dass deine Tastenkombination für Bilder nach einem Neustart oder Update wieder von selbst funktioniert. Sie kommt automatisch über die Update-Anzeige.

**Behoben: Tastenkombination für Bilder**
- **Nach Neustart und Update:** Bisher konnte die Kombination danach still ausfallen, weil das alte Programm sie noch kurz belegt hielt. AeroACARS versucht es jetzt von selbst weiter, bis sie wieder angemeldet ist. Neu belegen ist nicht mehr nötig.
- **Kombination ändern:** Ist die neue schon von einem anderen Programm belegt, bleibt deine bisherige aktiv und du siehst den Fehler. Bisher ging danach gar keine mehr.

**Yoke-Knopf**
- Falls dein Yoke-Knopf nach einem Neustart nicht reagiert, belege ihn bitte einmal neu. Diese Version schreibt ins Protokoll, ob das Gerät wiedergefunden wurde, damit wir die Ursache finden können. Schick in dem Fall bitte eine Diagnose aus der App.

### Bitte beachten
- Startet AeroACARS nach dem Update auf dem Mac nicht von selbst neu, öffne bitte **AeroACARS 3** selbst, nicht das daneben installierte AeroACARS 2.
- Weiterhin nicht gleichzeitig mit 2.x starten.
- Findest du einen Fehler, schick bitte eine Diagnose aus der App.

## 🇬🇧 English

### AeroACARS 3 – Beta 2.7

This version makes your picture hotkey work again by itself after a restart or update. It arrives automatically through the update notice.

**Fixed: hotkey for pictures**
- **After a restart or update:** the hotkey could silently stop working because the old program still held it for a moment. AeroACARS now keeps trying until it is registered again. You no longer need to set it again.
- **Changing the hotkey:** if the new one is already taken by another program, your current one stays active and you see the error. Until now no hotkey worked after that.

**Yoke button**
- If your yoke button does not respond after a restart, please assign it once more. This version logs whether the device was found again, so we can track down the cause. In that case please send a diagnosis from the app.

### Please note
- If AeroACARS does not restart by itself after the update on Mac, please open **AeroACARS 3** yourself, not the AeroACARS 2 installed next to it.
- Still do not run it at the same time as 2.x.
- If you find a problem, please send a diagnosis from the app.
