# v1.2.2 — PDC und CPDLC über das Hoppie-Netz

## 🇩🇪 Deutsch

**Neuer Tab „PDC/CPDLC": Startfreigaben anfordern und Datalink-Nachrichten mit ATC austauschen — direkt im Client, ohne externes Tool.**

AeroACARS spricht jetzt das kostenlose Hoppie-ACARS-Netz (hoppie.nl). Zwei Dinge, die bewusst getrennt bleiben, weil sie unterschiedlich funktionieren:

- **PDC** (Pre-Departure Clearance): Die Anfrage geht als Telex direkt an die Station, die die Freigabe erteilt. Keine Anmeldung nötig. Die eingehende Freigabe lässt sich mit einem Klick quittieren.
- **CPDLC**: Eine echte Datalink-Sitzung mit einem Center. Dafür meldest du dich an; kündigt ein Center die Übergabe an, meldet AeroACARS dich automatisch beim nächsten an.

Darüber steht der ACARS-Empfang selbst — nur die Verbindung zum Hoppie-Netz, damit Nachrichten überhaupt ankommen. Das ist noch keine Anmeldung bei einer Station.

**Antworten wie im Cockpit.** Jede Nachricht, die eine Antwort braucht, trägt ihre Tasten direkt an sich: WILCO, UNABLE, STANDBY bei Anweisungen, AFFIRM/NEGATIVE bei Rückfragen, ROGER zur Kenntnisnahme. Die Beschriftung ist bewusst der echte Datalink-Befehl, damit sichtbar ist, was gesendet wird. Antworten sind zweistufig: antippen, dann senden — ein Fehlklick soll keine Freigabe quittieren. STANDBY schließt eine Anweisung nicht, sie bleibt offen, bis eine echte Antwort rausgeht.

**Nachrichten schreiben** über ein kurzes Menü statt einer endlosen Liste: Anfragen, Wann erwartbar, Melden, Notfall, Freitext. Wer das ganze ICAO-Vokabular braucht, findet es über die Suche.

**Benachrichtigungen**, auch wenn du woanders bist: Ton, Systemhinweis und ein Banner über allen Tabs. Alles abschaltbar in den Einstellungen; das Feature selbst ist standardmäßig aus und muss dort erst eingeschaltet werden.

**Einstellungen:** Hoppie-Logon-Code (mit Prüf-Knopf) unter Einstellungen → Hoppie. Dein Callsign trägst du direkt im PDC/CPDLC-Tab ein — es muss exakt dem entsprechen, mit dem du im Netzwerk verbunden bist, denn genau darüber findet ATC dich.

**Für VA-Owner:** Keine Wire-Format-Änderung, `aeroacars-live` muss nicht mit-deployed werden. Das Feature ist opt-in und berührt Piloten nicht, die es nicht einschalten.

### Gegen die Lotsen-Software geprüft

Das Ganze wurde gegen **vSMR** geprüft — das Controller-Plugin, das auf VATSIM UK im Einsatz ist — und dabei mehrere Dinge korrigiert, die einem Lotsen sonst aufgefallen wären:

- Nachrichten, die ein Lotse als reinen Text schickt (*Standby*, *„Rufen Sie mich per Funk"*), wurden verworfen. Er hätte gesehen, dass zugestellt wurde, beim Piloten wäre nichts angekommen. Kommen jetzt an.
- Bestätigungen gehen immer in Großbuchstaben raus — die Gegenstelle vergleicht Groß-/Kleinschreibung, eine kleingeschriebene Antwort wäre für sie unsichtbar gewesen.
- Eine Bestätigung, die Wörter wie `CLR` oder `REQUEST` enthält, wird von der Lotsen-Software als *neue* Freigabeanfrage gelesen. Solche Antworten werden jetzt abgewiesen, statt beim Lotsen erneut aufzublinken.
- Freigaben kommen mit `@` als Zeilentrenner. Die wurden als eine unlesbare Zeile angezeigt und werden jetzt korrekt umgebrochen.
- Der Abrufrhythmus blieb nach einer Anmeldung dauerhaft bei 20 Sekunden statt der empfohlenen 45–75. Hoppie ist ein ehrenamtlich betriebener Gratis-Dienst; das ist behoben.
- Beim Beenden, Abmelden und Center-Wechsel wird die Sitzung sauber beendet. Endet der Client unsauber (Absturz), wird die zurückgebliebene Sitzung beim nächsten Start aufgeräumt — aber nur dann, nicht bei jedem Verbinden.

## 🇬🇧 English

**New "PDC/CPDLC" tab: request departure clearances and exchange datalink messages with ATC — inside the client, no external tool.**

AeroACARS now talks to the free Hoppie ACARS network (hoppie.nl). Two things, deliberately kept apart because they work differently:

- **PDC** (Pre-Departure Clearance): the request goes out as a telex straight to the station issuing the clearance. No logon needed. An incoming clearance can be acknowledged with one click.
- **CPDLC**: a real datalink session with a centre. You log on for it; when a centre announces a handover, AeroACARS logs you on to the next one automatically.

Above both sits ACARS reception itself — just the link to the Hoppie network so messages can reach you. That is not yet a logon with any station.

**Answering works like the cockpit does.** Every message needing a reply carries its keys: WILCO, UNABLE, STANDBY for instructions, AFFIRM/NEGATIVE for queries, ROGER to acknowledge. Labels are the actual datalink commands on purpose, so what gets sent is visible. Replies are two-step — press, then send — because a stray click must not acknowledge a clearance. STANDBY does not close an instruction; it stays open until a real answer goes out.

**Composing messages** through a short menu instead of an endless list: Request, When can we expect, Report, Emergency, Free text. The full ICAO vocabulary is still there behind the search box.

**Alerts even when you're elsewhere:** sound, a system notification, and a banner across every tab. All of it can be switched off in settings; the feature itself is off by default and has to be enabled there first.

**Settings:** Hoppie logon code (with a verify button) under Settings → Hoppie. Your callsign goes directly in the PDC/CPDLC tab — it must match exactly the one you are connected to the network with, since that is how ATC looks you up.

**For VA owners:** no wire-format change, `aeroacars-live` does not need co-deploying. The feature is opt-in and does not affect pilots who leave it off.

### Checked against the controller software

All of this was audited against **vSMR** — the controller plugin used on VATSIM UK — which turned up several things a controller would otherwise have noticed:

- Messages a controller sends as plain text (*Standby*, *"call me on frequency"*) were being discarded. They saw it delivered; the pilot got nothing. They arrive now.
- Acknowledgements always go out uppercase — the receiving end compares case-sensitively, so a lowercase reply was invisible to it.
- An acknowledgement containing words like `CLR` or `REQUEST` is read by the controller's software as a *new* clearance request. Those replies are now refused rather than making the request flash again on their screen.
- Clearances arrive with `@` as a line separator. They were shown as one unreadable line and are now broken correctly.
- The polling rate stayed pinned at 20 seconds after a logon instead of the recommended 45–75. Hoppie is a free, volunteer-run service; that is fixed.
- Sessions are ended cleanly on quit, logoff and centre change. If the client dies unexpectedly, the leftover session is cleared on the next start — but only then, not on every connect.
