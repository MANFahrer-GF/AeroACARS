## 🇩🇪 Deutsch

Diese Version macht die Installation des X-Plane-Plugins leichter, wenn AeroACARS den X-Plane-Ordner nicht von selbst findet.

### X-Plane-Ordner per Dialog auswählen

Bei manchen Installationen unter Windows und macOS fand die „Auto-Erkennung" den X-Plane-Ordner nicht, und der Pfad musste von Hand eingetippt werden. Jetzt gibt es in den Einstellungen unter **Plugins → X-Plane Premium Plugin** neben „Auto-Erkennung" den Knopf **„Ordner wählen …"**. Er öffnet den gewohnten Ordner-Dialog, du klickst dich zu deinem X-Plane-Ordner und bestätigst.

- Erwischst du dabei einen Unterordner, etwa `Resources`, `Resources/plugins` oder auf dem Mac `X-Plane.app`, findet AeroACARS den richtigen Hauptordner selbst.
- Liegt im gewählten Ordner kein X-Plane, erklärt ein Hinweis, welcher Ordner gemeint ist: der, in dem X-Plane und der Unterordner „Resources" liegen.

Danach wie gewohnt **„Plugin installieren"** klicken und X-Plane neu starten.

### Hinweis für VA-Betreiber

Der Client braucht keine Server-Änderung (`aeroacars-live`).

## 🇬🇧 English

This version makes installing the X-Plane plugin easier when AeroACARS cannot find the X-Plane folder on its own.

### Choose the X-Plane folder in a dialog

On some Windows and macOS installs, "Auto-detect" did not find the X-Plane folder and the path had to be typed in by hand. Settings → **Plugins → X-Plane Premium Plugin** now has a **"Choose folder…"** button next to "Auto-detect". It opens the usual folder dialog; browse to your X-Plane folder and confirm.

- If you pick a subfolder such as `Resources`, `Resources/plugins` or, on the Mac, `X-Plane.app`, AeroACARS finds the right root folder by itself.
- If there is no X-Plane in the chosen folder, a note explains which folder is meant: the one that contains X-Plane and its "Resources" subfolder.

Then click **"Install plugin"** as usual and restart X-Plane.

### Note for VA operators

The client needs no server change (`aeroacars-live`).
