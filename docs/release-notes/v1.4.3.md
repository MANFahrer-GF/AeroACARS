## 🇩🇪 Deutsch

### Karte

- **Live-Karte hing beim Rauszoomen fest, zeigte keinen Verkehr mehr.** Ursache: "Folgen" schaltete sich nur bei einem echten Ziehen der Karte ab, nicht beim Zoomen — und Zoomen per Mausrad verschiebt in MapLibre den Kartenmittelpunkt (es wird um den Cursor gezoomt, nicht um die Mitte). Sobald diese Verschiebung eine Schwelle überschritt, sprang die Kamera beim nächsten Positions-Update hart zurück auf einen engen Phasen-Zoom — und machte jeden Rauszoom-Versuch binnen einer Sekunde wieder rückgängig. Jetzt bleibt beim Zurückzentrieren der eigene Zoom erhalten; nur ein bewusstes (Wieder-)Einschalten von "Folgen" setzt noch einen festen Zoom.
- **Flugphase fehlte im Datenfeld.** Stand zwar schon als kleiner, gedimmter Text in der Fußzeile — aber neben den fetten Höhe/GS/Rest/ETA-Werten fiel das nicht auf. Jetzt eine eigene, gleich große Zeile im Hauptbereich der Flugwerte-Kachel.
- **Ereignisliste:** Die Alle/Flug/ACARS/System-Filterleiste passte nicht — raus, jetzt werden immer alle Einträge angezeigt.
- **Kartenschalter-Block** (Karte/Satellit, Norden/Kurs, Ebenen) wirkte zu groß und dominant — Knöpfe und Abstände verkleinert, gleiche Beschriftung, gleiche Klickflächen.

### Cockpit / Aktiver Flug

- **Flugphase stand doppelt** im Header (Badge neben der Flugnummer UND groß in der Phasen-Karte darunter) — Badge im Header entfernt, Phasen-Karte bleibt die einzige Anzeige.
- **Falsches Distanz-Feld im Header.** Die nmi-Anzeige neben Abflug→Ziel zeigte die bisher geflogene Strecke (zählt bei 0 los), nicht die Gesamtstrecke der Route. Jetzt wird die echte Gesamtstrecke berechnet (Großkreis-Distanz zwischen den Flughäfen). Die "Strecke" in der Trip-Karte bleibt unverändert — dort ist der Flugfortschritt richtig.
- **Masse/Flug/Trip/Loadsheet/Wetter-Kachel** nochmal verkleinert (Schrift/Abstände), spart weiter Höhe im Aktiver-Flug-Panel.

### Gebuchte Flüge

- **Leerzustand ("Keine Flüge gebucht") wirkte unprofessionell** neben dem Cockpit-Leerzustand — war bewusst als nackte Zeile ohne Illustration gebaut. Jetzt dieselbe Kachel-Gestaltung wie im Cockpit (Symbol, Titel, Hinweistext, Button).

### Logbuch

- **Abfrage gehärtet:** Eine kurze phpVMS-Störung zeigte bisher sofort einen Fehler ohne jede Wiederholung. Fehlgeschlagene Ladeversuche werden jetzt bis zu zweimal automatisch wiederholt (nur bei Verbindungs-/Zeitüberschreitungs-Fehlern, nicht bei Anmeldefehlern); zusätzlich gibt's jetzt einen "Erneut versuchen"-Button.

### CPDLC

- **Callsign-Zeile oben** ließ rechts sichtbar Platz frei liegen (Rest eines früheren Umbaus, bei dem der Anmelde-Block in einen anderen Bereich umgezogen ist) — Zeile neu verteilt, Callsign-Eingabefeld verbreitert.

### Landungen

- **Live-Vorschau nach der Landung verdeckte die Liste.** Der volle Berichtsblock stand ohne Höhenbegrenzung über der eigentlichen Übersicht — jetzt höhenbegrenzt mit eigenem Scrollbereich, die Liste bleibt sichtbar.

### Hinweis

Reines Client-Update — aktualisiert sich automatisch, kein Wire-Format geändert.

## 🇬🇧 English

### Live Map

- **The map used to get stuck when zooming out, hiding other traffic.** Root cause: "Follow" only disengaged on a real drag, not on a zoom gesture — and MapLibre's scroll-zoom pivots around the cursor, not the map center, shifting the center away from the aircraft. Once that drift crossed a threshold, the camera snapped hard back to a tight phase-based zoom on the very next position update, undoing any zoom-out attempt within about a second. The current zoom is now preserved when recentering; only a deliberate (re-)engage of "Follow" still sets a fixed zoom.
- **Flight phase was missing from the data field.** It was already shown as small, dim footer text — but easy to miss next to the bold altitude/GS/remaining/ETA values. Now its own full-size row in the main flight-data card.
- **Event list:** the All/Flight/ACARS/System filter bar didn't fit — removed, every entry now always shows.
- **Map-switcher overlay** (Map/Satellite, North/Track, layers) felt oversized and too dominant — buttons and spacing trimmed down, same labels, same click targets.

### Cockpit / Active Flight

- **Flight phase shown twice** in the header (a badge next to the flight number AND large in the phase card below) — removed the header badge, the phase card stays the single display.
- **Wrong distance field in the header.** The nmi shown next to the departure→arrival route used to be the distance flown so far (starts at 0, counts up), not the route's total distance. Now computes the real total (great-circle distance between the airports). The Trip card's own "Distance" is unchanged — that one correctly shows flight progress.
- **Weight/Flight/Trip/Loadsheet/Weather cards** trimmed down again (font/spacing), saving further height in the Active Flight panel.

### Booked Flights

- **The empty state ("No flights booked") looked unprofessional** next to Cockpit's own empty state — it was deliberately built as a bare row with no illustration. Now uses the same card treatment as Cockpit's (icon, title, hint, button).

### Logbook

- **Query hardened:** a brief phpVMS hiccup used to show an error immediately with no retry at all. Failed loads now automatically retry up to twice (only for connection/timeout-looking errors, not auth failures); there's also a manual "Try again" button now.

### CPDLC

- **The callsign row at the top left visible space unused on the right** (left over from an earlier restructure that moved the logon block elsewhere) — row redistributed, callsign input widened.

### Landings

- **The live preview after touchdown covered the list.** The full report card had no height cap sitting above the actual overview — now height-capped with its own scroll area, the list stays visible.

### Note

Pure client update — auto-updates, no wire-format changes.
