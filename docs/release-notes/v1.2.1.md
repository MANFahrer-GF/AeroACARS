# v1.2.1 — Korrekte Touchdown-Zählung im Flugbericht

## 🇩🇪 Deutsch

**Kurzer Nachzügler zu v1.2.0, noch am selben Tag: eine Anzeige-Ungenauigkeit im Flugbericht behoben.**

Bei manchen — auch völlig normalen und guten — Landungen zeigte der Flugbericht "0 Touchdowns", obwohl tatsächlich sauber gelandet wurde. Ursache: der interne Landungs-Zähler wurde nur befüllt, wenn ein einzelner Erfassungs-Tick exakt die Lande-Phase erwischt hat — bei sehr schneller Verzögerung konnte dieser Tick übersprungen werden, während die eigentliche Landungs-Erfassung (Sinkrate, G-Kraft, Position) unabhängig davon trotzdem korrekt vorlag. Der Flugbericht wirkte dadurch fälschlich lückenhaft, obwohl der Score selbst nie betroffen war.

AeroACARS rekonstruiert jetzt konsistent: liegt eine echte Landung vor, aber fehlt der zugehörige Zähler-Eintrag, wird er aus den bereits vorhandenen echten Messwerten ergänzt — an allen drei Stellen, an denen die Touchdown-Zahl im Flugbericht auftaucht (Zähler, Freitext-Zusammenfassung, PIREP-Felder). Betrifft nur die Anzeige/den Bericht, keine Bewertung.

Kleines Aufräumen nebenbei: eine harmlose Compiler-Warnung beim Bauen wurde stillgelegt (kein Verhaltensunterschied).

## 🇬🇧 English

**Short same-day follow-up to v1.2.0: a display inaccuracy in the flight report is fixed.**

On some — including perfectly normal, good — landings, the flight report showed "0 touchdowns" even though the landing was clean. Root cause: the internal touchdown counter was only populated when a single sampling tick happened to catch the landing phase exactly — under very fast deceleration that tick could get skipped, while the actual landing capture (sink rate, G-force, position) was independently still correct. The report looked falsely incomplete even though the score itself was never affected.

AeroACARS now reconstructs consistently: if a genuine landing occurred but the counter entry is missing, it's backfilled from the real measurements that were already captured — across all three places the touchdown count appears in the flight report (counter, plain-text summary, PIREP fields). Report/display only, no scoring impact.

Small unrelated cleanup: silenced a harmless compiler warning during builds (no behavior change).
