## 🇩🇪 Deutsch

### Kabinenansagen: einfacher einstellen, der Server macht den Rest

- **Nur noch eine Sprachwahl.** Du wählst „Airline-Sprache + Englisch“ oder „Airline-Sprache + Deutsch“. Welche Stimme spricht, bestimmt der GSG-Server je Sprache: Englisch spricht Kokoro, alle anderen Sprachen Piper. Fällt Kokoro einmal aus, springt Piper ein.
- **Weniger Auswahlfelder.** Die Stimmenwahl je Rolle (Kapitän, Kabine, Kommandos) und die Tagesform je Rolle sind weg. Die Tagesform der Crew würfelt der Server für jeden Flug neu, damit die Ansagen abwechslungsreich bleiben.
- **Azure entfernt.** Die Ansagen kommen komplett kostenlos vom GSG-Server, ein eigener Schlüssel wird nicht mehr gebraucht. Ein früher gespeicherter Azure-Schlüssel wird beim Start aus dem Schlüsselbund gelöscht.

Alles andere ist wie in beta.3. Panel, Flow-Widget und X-Plane-Plugin brauchen kein Update.

## 🇬🇧 English

### Cabin announcements: simpler settings, the server does the rest

- **A single language choice.** You choose "Airline's language + English" or "Airline's language + German". Which voice speaks is decided by the GSG server for each language: English is spoken by Kokoro, all other languages by Piper. If Kokoro is unavailable, Piper takes over.
- **Fewer settings.** The voice choice per role (captain, cabin, commands) and the mood per role are gone. The server rolls the crew's mood for each flight, so the announcements stay varied.
- **Azure removed.** The announcements come entirely free from the GSG server, no own key is needed any more. An Azure key stored earlier is deleted from the keychain at startup.

Everything else is as in beta.3. The panel, the Flow widget and the X-Plane plugin do not need an update.
