## 🇩🇪 AeroACARS v1.5.0-beta.2 — MSFS-In-Sim-Panel (Testbuild)

**Weiterhin ein interner Testbuild, kein regulärer Release.** Bleibt als Vorabversion markiert, unsichtbar für andere Piloten.

**Neu gegenüber v1.5.0-beta.1:** Die LAN-Fernbedienung (Einstellungen → Fernzugriff) lehnt jetzt explizit ab, wenn ihr Port auf `47847` gesetzt wird — genau der feste Port, den der neue MSFS-Panel-Server exklusiv nutzt. Verhindert versehentliche Port-Kollisionen zwischen den beiden unabhängigen lokalen Servern.

Alles andere unverändert gegenüber beta.1: eigener, immer aktiver Panel-Server (Port 47847, `127.0.0.1`-only) für das MSFS-In-Sim-Panel, komplett getrennt von der Fernbedienung (Port 8765, weiterhin PIN-geschützt, weiterhin optional). Keine Wire-Format-Änderungen, keine Auswirkung auf Scoring/PIREP/Landung.

Das eigentliche MSFS-Panel-Paket (`msfs-panel/` im Repo) bleibt ein separat über das MSFS SDK gebautes Paket, kein Teil dieses Installers — die zwischenzeitliche Design-Überarbeitung und das neue Ruhig/Wach-Verhalten des Panels liegen dort im Quellcode, nicht in diesem Build.

## 🇬🇧 AeroACARS v1.5.0-beta.2 — MSFS in-sim panel (test build)

**Still an internal test build, not a regular release.** Stays flagged as a prerelease, invisible to other pilots.

**New since v1.5.0-beta.1:** The LAN Remote Control server (Settings → Fernzugriff) now explicitly rejects being set to port `47847` — the exact fixed port the new panel server exclusively uses. Prevents an accidental port collision between the two independent local servers.

Everything else is unchanged from beta.1: a dedicated, always-on panel server (port 47847, `127.0.0.1` only) for the MSFS in-sim panel, fully separate from the Remote Control server (port 8765, still PIN-protected, still opt-in). No wire-format changes, no impact on scoring/PIREP/landing logic.

The actual MSFS panel package (`msfs-panel/` in the repo) remains a separately-built MSFS SDK package, not part of this installer — the interim visual redesign and the panel's new quiet/wake behavior live there in source, not in this build.
