## 🇩🇪 Deutsch

Diese Version bringt das X-Plane-Plugin 1.1.1. Es behebt einen Fehler, durch den das HUD-Band in X-Plane unsichtbar blieb.

### HUD-Band auf einem zweiten Monitor

Lief X-Plane auf einem zweiten Monitor, erschien das HUD-Band nicht. Je nach Anordnung der Bildschirme legte das Plugin das Band außerhalb des sichtbaren Bereichs an, und X-Plane zeichnete es dann nie. Telemetrie und Landemessung waren davon nicht betroffen. Plugin 1.1.1 holt das Band jetzt auf den Bildschirm, bevor es angezeigt wird. Das gilt auch, wenn X-Plane während des Flugs auf einen anderen Monitor wechselt.

### So kommst du an das neue Plugin

Läuft bei dir Plugin 1.1.0, zeigt AeroACARS unter **Einstellungen → Plugins → X-Plane Premium Plugin** den Hinweis **„Plugin-Update verfügbar"**. Darunter das Plugin neu installieren und X-Plane neu starten. Deine Position und Größe des Bands bleiben erhalten.

### Hinweis für VA-Betreiber

Der Client braucht keine Server-Änderung (`aeroacars-live`).

## 🇬🇧 English

This version ships X-Plane plugin 1.1.1. It fixes a bug that kept the HUD band invisible in X-Plane.

### HUD band on a second monitor

When X-Plane ran on a second monitor, the HUD band did not appear. Depending on how the screens were arranged, the plugin created the band outside the visible area, and X-Plane then never drew it. Telemetry and touchdown capture were not affected. Plugin 1.1.1 now moves the band onto the screen before showing it. This also applies when X-Plane switches to another monitor during a flight.

### How to get the new plugin

If you run plugin 1.1.0, AeroACARS shows **"Plugin update available"** under **Settings → Plugins → X-Plane Premium Plugin**. Reinstall the plugin there and restart X-Plane. The band's position and size are kept.

### Note for VA operators

The client needs no server change (`aeroacars-live`).
