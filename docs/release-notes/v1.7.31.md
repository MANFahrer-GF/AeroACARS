## 🇩🇪 Deutsch

### Frachtflug im Passagierflugzeug bremst den Auto-Start nicht mehr aus

Wer einen Frachtflug gebucht hatte, bekam vom Client teils die Meldung „Aircraft passt nicht“ — und damit keinen automatischen Start. Ob das passierte, hing nicht am Flugzeug, sondern an der Schreibweise des Add-ons: Meldete der Simulator `MD-11`, galt es als Mismatch; meldete er `MD11`, ging es durch.

**Der Grund:** AeroACARS kann einen Frachter nicht verlässlich erkennen. Es sieht nur ein `F` am Ende der Kennung oder das Wort „Freighter“ im Titel. Viele Add-ons melden ihre Frachtversion aber schlicht als Passagiermuster. Die Prüfung bestrafte damit die Schreibweise des Herstellers, nicht das falsche Flugzeug.

**Jetzt:** Eine Frachtbuchung passt zum Flugzeug derselben Baureihe im Simulator — `MD11F` zu `MD-11`, `B74F` zu `747-400`, `B763F` zu `767-300` und so weiter. Das gilt für alle Frachtmuster gleich. Die Zuordnung bleibt im Übrigen streng: Ein wirklich anderes Muster, etwa ein A320 statt einer 737, wird weiterhin gemeldet. Muster, bei denen das `F` nur zur Baureihe gehört — zum Beispiel die Mooney `M20F` —, sind davon nicht betroffen.

Welches Flugzeug zu einem Frachtflug gehört, bleibt damit eine Sache der Dispatch-Disziplin und nicht die eines Zeichenkettenvergleichs.

## 🇬🇧 English

### A cargo flight in a passenger aircraft no longer blocks auto-start

If you had booked a cargo flight, the client sometimes reported "aircraft does not match" — and therefore refused to start automatically. Whether that happened did not depend on the aircraft, but on the add-on's spelling: if the simulator reported `MD-11`, it counted as a mismatch; if it reported `MD11`, it passed.

**The reason:** AeroACARS cannot reliably recognise a freighter. It only sees an `F` at the end of the code or the word "Freighter" in the title. Many add-ons, however, report their cargo version simply as the passenger type. The check therefore punished the vendor's spelling, not the wrong aircraft.

**Now:** A cargo booking matches the aircraft of the same series in the simulator — `MD11F` with `MD-11`, `B74F` with `747-400`, `B763F` with `767-300` and so on. This applies to all cargo types alike. The rest of the matching stays strict: a genuinely different type, an A320 instead of a 737 for example, is still reported. Types where the `F` merely belongs to the series — the Mooney `M20F`, for instance — are not affected.

Which aircraft belongs to a cargo flight thus remains a matter of dispatch discipline, not of a string comparison.
