## 🇩🇪 Deutsch

### X-Plane: Zibo 737 wird jetzt richtig gelesen

Beim Zibo 737-800 standen bisher mehrere Anzeigen dauerhaft falsch. Nachgeprüft an einem echten Flug und an der Zibo-Dokumentation – jetzt werden richtig erkannt:

- **Autopilot** – mit CMD A **und** CMD B (bisher stand er immer auf „aus“)
- **Taxilicht** und **Logo-Licht** (das Logo-Licht war bisher eine Kopie der Positionslichter)
- **Sonden-Heizung** und **Anti-Eis** (Triebwerke und Flügel)
- **Master Caution**

Der mitgelieferte Boeing 737-800 von X-Plane 12 nutzt dieselben Schalter und profitiert mit (außer beim Logo-Licht, das er nicht hat). Für alle anderen X-Plane-Flugzeuge bleibt alles wie bisher.

### MSFS: weniger Warnungen im Protokoll

Beim ersten Öffnen des Telemetrie-Monitors, beim Start von „Flugzeug vermessen“ und im Variablen-Inspektor hat AeroACARS Datenabfragen vorsorglich gestoppt, die es noch gar nicht gab. MSFS hat das jeweils mit einer Warnung beantwortet. Das passiert jetzt nicht mehr. An der Funktion ändert sich nichts.

Hinweis: Die Zeile zu diesen Warnungen in den Notes von 1.9.14 nannte die Ursache falsch – erst mit dieser Version sind sie wirklich weg.

## 🇬🇧 English

### X-Plane: Zibo 737 is now read correctly

Several readings of the Zibo 737-800 used to be permanently wrong. Checked against a real flight and the Zibo documentation – now read correctly:

- **Autopilot** – with CMD A **and** CMD B (it previously always showed “off”)
- **Taxi light** and **logo light** (the logo light used to mirror the navigation lights)
- **Probe heat** and **anti-ice** (engines and wings)
- **Master caution**

The Boeing 737-800 that ships with X-Plane 12 uses the same switches and benefits as well (except the logo light, which it does not have). Nothing changes for any other X-Plane aircraft.

### MSFS: fewer warnings in the log

When first opening the telemetry monitor, starting “Measure aircraft” and in the variable inspector, AeroACARS used to stop data requests that did not exist yet. MSFS answered each of them with a warning. This no longer happens. Functionality is unchanged.

Note: the line about these warnings in the 1.9.14 notes named the wrong cause – only this version actually removes them.
