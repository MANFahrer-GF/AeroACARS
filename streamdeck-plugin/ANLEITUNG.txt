AeroACARS-Tasten auf eigene Seiten legen
==========================================

Die mitgelieferten Profile sind nur ein Vorschlag. Jede AeroACARS-Taste
lässt sich einzeln auf jede Seite, jeden Ordner und jedes Profil legen –
auch mehrfach und auf mehreren Decks gleichzeitig.

1. TASTE AUF EINE EIGENE SEITE ZIEHEN
   - StreamDeck-Software öffnen, oben das gewünschte Profil wählen.
   - Rechts in der Aktionsliste die Kategorie "AeroACARS" aufklappen
     (31 Tasten, 4 Drehregler).
   - Eine Aktion, z. B. "Sprit" oder "Kabine stumm", mit der Maus auf
     eine freie Taste ziehen. Fertig – sie zeigt sofort den Live-Wert.
   - Belegte Taste ersetzen: einfach darüber ziehen.
   - Taste entfernen: Rechtsklick auf die Taste -> Löschen.

2. EIGENE SEITE ODER EIGENEN ORDNER ANLEGEN
   - Seite: unten unter der Tastenansicht auf "+" (neue Seite).
     Zwischen Seiten wechselt man mit den Aktionen "Nächste Seite" /
     "Vorherige Seite" aus der Kategorie "Navigation".
   - Ordner: Aktion "Ordner erstellen" (Kategorie "Navigation") auf eine
     Taste ziehen, doppelklicken, dann AeroACARS-Aktionen hineinziehen.
     Oben links im Ordner setzt das StreamDeck automatisch "Zurück".

3. ZUM AEROACARS-PROFIL SPRINGEN UND ZURÜCK
   - In deinem normalen Profil die Aktion "AeroACARS öffnen" (Kategorie
     "AeroACARS") auf eine Taste legen. Ein Druck wechselt ins
     AeroACARS-Profil dieses Decks (15er, XL oder +).
   - Zurück kommst du über die Phasen-Taste (oben links, kleiner Pfeil).
   - WICHTIG: Das Zurück funktioniert nur, wenn du mit "AeroACARS öffnen"
     hingewechselt bist. Wählst du das Profil von Hand in der
     StreamDeck-Software, kennt das Plugin keinen Rückweg.
   - Die Phasen-Taste springt immer ins vorherige Profil. Legst du sie in
     dein eigenes Profil, springt sie auch von dort weg.

4. STREAMDECK + (DREHREGLER)
   - Die vier Regler-Aktionen ("Regler Ansagen", "Regler Musik",
     "Regler Flugdaten", "Regler Wetter") auf einen Drehregler ziehen.
     Normale Tasten-Aktionen funktionieren auf den 8 Tasten des +.

5. WAS DIE TASTEN TUN
   Anzeigetasten:
     - kurz drücken   = nächste Ansicht (die Punkte oben rechts zeigen,
                        wie viele es gibt), z. B. Sprit an Bord -> Plan Block
                        -> Plan Trip, Wetter Wind -> Sicht/Wolken -> Temp,
                        GS -> V/S -> Wind, UTC -> Ortszeit, Flug -> Muster
     - lang drücken   = AeroACARS kommt nach vorn, auf der passenden Seite
                        (Hoppie -> CPDLC, Landung/Note -> Landung,
                        Sprit/Wetter/Bahn -> Briefing, GS/Strecke -> Karte,
                        Ansage -> Kabine, sonst Cockpit)
     - Phase: kurz = zurück ins vorige Profil, lang = Cockpit
   Bedientasten: AeroACARS öffnen (Profil), Kabine stumm (1 s halten),
     Ansagen/Musik leiser/lauter, Musik-Lautstärke (drücken = Musik stumm),
     Boarding-Musik an/aus, VATSIM CDM (öffnet das Fenster).
   Langer Druck, Kabine und CDM brauchen das neue AeroACARS (Dev-Build im
   Ordner); mit v2.1.10 zeigen sie ein Warnzeichen bzw. "Client zu alt".

Hinweis: Eigene Titel braucht keine Taste – Beschriftung und Icon kommen
vom Plugin. Ein Titel aus der StreamDeck-Software würde darübergelegt.
